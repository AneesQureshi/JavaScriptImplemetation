# JavaScript Implementation Examples

Collection of JavaScript programs and practice snippets.  
Focuses on concepts relevant to QA automation such as arrays, functions, promises, async/await, and DOM interaction.

## Tech Stack
- JavaScript (ES6+)
- Node.js (runtime)
- VS Code (development)

## Project Structure
arrays.js          # Array methods (map, filter, reduce, etc.)  
functions.js       # Function declarations, expressions, arrow functions  
promises.js        # Callbacks, promises, async/await  
objects.js         # Objects & destructuring  
dom.js             # Sample DOM manipulation examples  

## Setup & Run
```bash
node arrays.js
node functions.js
```

## Features Covered
- Array methods (push, pop, shift, unshift, slice, splice, map, filter, reduce, find, forEach)
- Functions: declarations, expressions, arrow functions
- Template literals
- Promises, async/await
- Object destructuring and spread operator
- DOM examples (querySelector, event handling)

## Usage
Use as a reference repo for:
- JavaScript practice
- QA automation scripting
- Technical interview preparation
